# OmniView

מערכת SaaS לניהול רצפת ייצור — מעקב פקודות עבודה, שלבי עבודה, מספרים סידוריים,
ביצועי עובדים ודוחות בזמן אמת. נארזת כ-PWA וניתנת להתקנה על טאבלט או מחשב ברצפת הייצור.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `index.html` | האפליקציה כולה — React + JSX בקובץ אחד |
| `landing.html` | דף נחיתה שיווקי |
| `manifest.json`, `sw.js` | הגדרות ה-PWA ו-Service Worker |
| `logo.svg` | מקור האמת של הלוגו |
| `app-icon.svg` | הלוגו על אריח ריבועי; ממנו נוצרים קובצי ה-PNG |
| `build.js` | הידור מוקדם של ה-JSX ל-`app.js` |
| `vercel-build.js` | שלב ה-build של Vercel — מריץ את `build.js` ומכין את `dist/` |
| `tools/sync-test.js` | בדיקות שכבת הסנכרון — מודדות כמה בייטים כל סבב עולה (`npm test`) |
| `training/employee-guide.html` | מצגת הדרכה לעובדים — התקנה, כניסה ודיווח, עם צילומי מסך מהאפליקציה |
| `SETUP.md` | הקמת Supabase, עדכוני סכימה ותיעוד הגרסאות |

## סנכרון

כל טבלה נושאת `updated_at` שנשמר על ידי טריגר במסד. הסבב התקופתי שואל רק
"מה השתנה מאז?" ולא קורא טבלאות שלמות, שינוי שמגיע ב-Realtime מוחל מתוך
ההודעה עצמה בלי קריאה נוספת, ועותק מקומי ב-IndexedDB שומר את השורות יחד עם
ה-watermark שלהן — כך שטאבלט שנפתח בבוקר מוריד את מה שזז מאתמול ולא 40MB.
מחיקה שבוצעה במכשיר אחר נתפסת בהשוואת מספר שורות (בקשת HEAD בלי גוף).

`npm test` מודד את כל זה מול PostgREST מדומה ונתונים בגודל של הייצור.

## הדרכת עובדים

`training/employee-guide.html` היא מצגת של 20 שקפים שמסבירה לעובד — ולא למנהל —
איך מתקינים את האפליקציה על אייפון ועל אנדרואיד, איך נכנסים, ומה בדיוק לוחצים
לאורך יום עבודה: תוכנית העבודה, ▶️ התחל, ⏸️ הפסקה, ✅ סיימתי ודיווח לפי כמות.

צילומי המסך שבה צולמו מהאפליקציה עצמה, במסך של טלפון, מול נתוני דמו — לא צוירו
ולא עברו רטוש. הקובץ עומד בפני עצמו: התמונות מוטמעות בתוכו, ולכן אפשר גם לשלוח
אותו במייל ולפתוח בלי רשת. מקשי ← → מעבירים בין שקפים, ⛶ למסך מלא, ו-⎙ מייצא ל-PDF.

מוגש גם באתר, בכתובת `/training/employee-guide.html`.

## לוגו

הלוגו הוא מונוגרמה "OV": ה-O הוא טבעת סרט שבתוכה שושנת מצפן (נראות 360°),
וה-V הוא חץ עולה מעל קו מגמה (תובנות וצמיחה).

`logo.svg` הוא מקור האמת. `app-icon.svg` הוא אותו לוגו על אריח ריבועי, וממנו
נוצרים `app-icon-192.png`, `app-icon-512.png` ו-`app-icon-maskable-512.png`.
אותה יצירה משוכפלת גם בתוך `index.html` בשלושה מקומות (סרגל הניווט, מסך הפתיחה
ומסך הטעינה) ובתוך `landing.html` — יש לעדכן את כולם יחד.

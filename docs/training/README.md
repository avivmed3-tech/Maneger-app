# מצגת הדרכה — הצד של המנהל

`OmniView-Manager-Guide.pptx` — 17 שקפים המלווים מנהל מחלקה או ראש צוות
בתפעול היומיומי של המערכת: איך מקצים עבודה, איך רואים בכל רגע מה כל עובד
עושה, ואיך דוגמים התקדמות.

כל צילומי המסך במצגת נלקחו מהאפליקציה עצמה (`index.html`), בהרצה מקומית עם
מערך נתוני הדגמה של מחלקת ההרכבה — אותם עובדים, שלבים ופק"ע שמופיעים ב-
`FALLBACK_USERS` ו-`DEF_STAGES`. הצילומים הבודדים שמורים ב-`screenshots/`
וניתן להשתמש בהם גם בחומרי עזרה אחרים.

## עדכון המצגת

הצילומים והמצגת נבנו מחוץ למאגר. כדי לרענן אותם יש להריץ את האפליקציה
מקומית, לצלם מחדש את המסכים הרלוונטיים לתוך `screenshots/`, ולהחליף את
התמונות במצגת — שמות הקבצים תואמים לסדר השקפים.
